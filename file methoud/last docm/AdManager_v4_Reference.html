How To Call Ads — Every Pattern

All examples use the verified method signatures from AdManager.cs. Copy-paste ready.

Rewarded Ads — Calling Patterns
🎁
Pattern A — Game Over: Revive / Continue Offer
OnGameOver() → shows RewardedPromptUI → rewarded ad on accept

The highest-value rewarded placement. Shows the prompt UI automatically. The 5-second countdown is built in.

// In your GameOverManager.cs:
void HandleGameOver()
{
    AdManager.Instance.OnGameOver(
        onRevived: () =>
        {
            // Player watched the ad and earned the revive
            _playerHealth = _maxHealth;
            ResumeGameplay();
        },
        onDied: () =>
        {
            // Player declined OR no rewarded ad was ready
            ShowGameOverScreen();
        }
    );
}
ℹ️
If no rewarded ad is ready, onDied fires immediately — no popup shown. The method fails gracefully so your game flow always continues.
💰
Pattern B — Double Reward Offer
OnDoubleRewardOffer() → shows prompt UI → 8-second countdown
// At level complete screen:
void ShowDoubleCoinsOffer(int coinsEarned)
{
    AdManager.Instance.OnDoubleRewardOffer(
        label:     "2× Coins",   // shown in the prompt UI
        onDoubled: () => { GiveCoins(coinsEarned * 2); ShowNextLevelButton(); },
        onSkipped: () => { GiveCoins(coinsEarned);      ShowNextLevelButton(); }
    );
}
🎯
Pattern C — Daily Bonus Offer
OnDailyBonusOffer() → no countdown by default
// In your DailyBonusManager.cs (guard daily cooldown yourself):
void ShowDailyBonus()
{
    AdManager.Instance.OnDailyBonusOffer(
        onClaimed: () =>
        {
            GiveDailyGems(50);
            PlayerPrefs.SetString("daily_bonus_date", DateTime.UtcNow.ToString("O"));
            PlayerPrefs.Save();
        }
    );
    // Note: if player ignores the popup, onClaimed is NOT called.
    // Only fires if they watch the ad OR no ad was ready (graceful give).
}
⏩
Pattern D — Skip Timer / Wait Offer
OnSkipTimerOffer() → 5-second countdown prompt
void ShowSkipTimerButton()
{
    skipButton.onClick.AddListener(() =>
    {
        AdManager.Instance.OnSkipTimerOffer(
            label:     "Skip 2h wait",
            onSkipped: () => { _timerSeconds = 0; UpdateTimerUI(); }
        );
    });
}
▶️
Pattern E — Direct Rewarded Ad (no prompt UI)
ShowRewarded() → shows ad immediately if ready

Use when you have your own custom UI for the offer and just need to show the ad directly.

// Check readiness before showing your watch button:
watchButton.gameObject.SetActive(AdManager.Instance.IsRewardedReady());

// On button click:
void OnWatchAdClicked()
{
    bool shown = AdManager.Instance.ShowRewarded(
        AdManager.Placement.UnlockContent,
        onRewarded: () =>
        {
            // Called by SDK when user earns the reward
            UnlockSkin("rare_hat");
        }
    );

    if (!shown)
    {
        // Ad wasn't ready — show fallback (buy with coins, etc)
        ShowBuyWithCoinsDialog();
    }
}
⚠️
Note: The onRewarded callback fires when the SDK confirms the reward was earned (before the ad closes). If the player skips the ad, the callback is NOT called. Listen to OnRewardSkipped event for skip handling.
Interstitial Ads — Calling Patterns
📺
Pattern F — Level Complete Interstitial
OnLevelComplete() → TryShowInterstitial() with all guards applied

The standard interstitial call. All guards (day-1, tutorial, cooldown, session cap) run automatically.

// Call every time a level ends — guards handle blocking early levels.
void CompleteLevel(int levelNumber)
{
    SaveProgress(levelNumber);
    AdManager.Instance.OnLevelComplete(levelNumber);
    // ShowLevelCompleteUI() here — don't wait for the ad
    ShowLevelCompleteUI();
}

// To run code AFTER the ad closes → subscribe to the event:
void OnEnable()
{
    AdManager.Instance.OnInterstitialClosed += HandleInterstitialClosed;
}
void HandleInterstitialClosed() { LoadNextLevelScene(); }
void OnDestroy()
{
    AdManager.Instance.OnInterstitialClosed -= HandleInterstitialClosed;
}
🔀
Pattern G — Manual Interstitial with Guards
TryShowInterstitial() directly on any custom trigger
void OnMenuOpen()
{

}

// OR manually trigger an interstitial at any point:
void OnShopClosed()
{
    if (!_isBossFight && !_isInCutscene)
        AdManager.Instance.TryShowInterstitial(AdManager.Placement.MenuTransition);

// Check readiness without showing (for optional/bonus triggers):

Universal Callback — React to Any Ad Completion
📡
Pattern J — Using OnAdsCompleted (Recommended for Analytics)
Single subscription point for all ad outcomes in any script

Subscribe once and handle all ad outcomes centrally. Works across scenes.

void OnEnable()
{
    AdManager.Instance.OnAdsCompleted += HandleAdsCompleted;
}

void HandleAdsCompleted(AdManager.AdsCompletedArgs args)
{
    switch (args.Type)
    {
        case AdManager.AdsCompletedType.RewardedEarned:
            // args.WasRewarded == true, args.PlacementName set
            GiveRewardForPlacement(args.PlacementName);
            AnalyticsManager.LogAdReward(args.PlacementName);
            break;

        case AdManager.AdsCompletedType.RewardedSkipped:
            AnalyticsManager.LogAdSkip(args.PlacementName);
            break;

        case AdManager.AdsCompletedType.InterstitialClosed:
            // args.PlacementName tells you which placement closed
            if (args.PlacementName == AdManager.Placement.LevelComplete)
                TransitionToNextLevel();
            break;

        case AdManager.AdsCompletedType.BannerLoaded:
            AdjustLayoutForBanner();
            break;
    }
}

void OnDestroy()
{
    if (AdManager.Instance != null)
        AdManager.Instance.OnAdsCompleted -= HandleAdsCompleted;
}

Pattern L — Remove Ads Purchase Flow
SetAdFree() → local unlock → SetAdFreeVerified() → server lock
// ── Step 1: Unity IAP purchase complete ────────────
void OnPurchaseComplete(PurchaseEventArgs args)
{
    AdManager.Instance.SetAdFree();
    // Banner disappears instantly. Interstitials blocked.
    StartReceiptValidation(args.purchasedProduct.receipt);
}

// ── Step 2: After server validates receipt ──────────
YourServer.ValidateReceipt(receipt, result =>
{
    AdManager.Instance.SetAdFreeVerified(result.isValid);
    // true  → permanently ad-free (server trust level)
    // false → 72h grace period only, then ads resume
});

// ── Check status anywhere ───────────────────────────
if (AdManager.Instance.IsAdFree())
{
    removeAdsButton.SetActive(false);
    ShowPremiumBadge();
}

SDK Initialization
void InitializeSDK() — private
AUTO
Category: Init Returns: void Called by: Start()

Called automatically in Start(). Never call manually. Reads the platform-correct app key, calls LevelPlay.Init(appKey), registers all events. On success loads Rewarded, Interstitial, and Banner. Up to 3 auto-retries with 30s delay on failure.

SAFE ANYTIME

REQUIRES READY
Category: Rewarded Returns: bool — true if ad shown v3 doc had wrong 3-param signature Fires: OnRewardGranted · OnRewardSkipped · OnAdsCompleted

Banner Ads
void LoadBanner()  /  void ShowBanner()  /  void HideBanner()  /  void DestroyBanner()
Category: Banner

LoadBanner() — creates LevelPlayBannerAd(bannerAdUnitId), registers events, calls .LoadAd(). On load success, calls ShowBanner() automatically. Usually called by OnMenuOpen().

ShowBanner() — calls .ShowAd(). Skipped if not loaded or already visible.

Section 4 · NEW — Universal Callback System

OnAdsCompleted — Universal Ad Event

A single event that fires for every ad outcome. Subscribe from any script in any scene. Pairs with the existing individual events (OnRewardGranted, etc.) — they are NOT mutually exclusive.

ℹ️
This system did not exist in v2. It was added in your v3 code as a universal callback for all ad completions. Use it for analytics, cross-scene reactions, and UI updates.

// AdsCompletedType enum values

TypeWasRewardedWhen it fires
RewardedEarnedtruePlayer watched rewarded ad to completion and earned reward
RewardedSkippedfalseRewarded ad was closed early (or show failed)
InterstitialClosedfalseInterstitial dismissed by player
BannerLoadedfalseBanner ad loaded and is now visible
AppOpenClosedfalseApp Open ad (foreground resume) was dismissed

// AdsCompletedArgs fields

FieldTypeDescription
args.TypeAdsCompletedTypeWhich ad type completed (see enum above)
args.PlacementNamestringThe placement string (e.g. "double_coins"). Empty for banners.
args.WasRewardedboolTrue only for RewardedEarned
args.AdInfostringSDK's LevelPlayAdInfo.ToString() — for logging/analytics

// Full example: centralized ad analytics handler

public class AdAnalyticsHandler : MonoBehaviour
{
    void OnEnable()
    {
        AdManager.Instance.OnAdsCompleted += OnAdCompleted;
    }

    void OnAdCompleted(AdManager.AdsCompletedArgs args)
    {
        // Send to Firebase, Adjust, etc.
        FirebaseAnalytics.LogEvent("ad_completed",
            "type",      args.Type.ToString(),
            "placement", args.PlacementName,
            "rewarded",  args.WasRewarded ? "1" : "0"
        );

        // React to type
        if (args.Type == AdManager.AdsCompletedType.RewardedEarned
         && args.PlacementName == AdManager.Placement.DoubleCoins)
        {
            DoubleCurrentCoins();
        }
    }

    void OnDestroy()
    {
        if (AdManager.Instance != null)
            AdManager.Instance.OnAdsCompleted -= OnAdCompleted;
    }
}
Section 5

All Events — Subscribe & Unsubscribe

Always unsubscribe in OnDestroy() to avoid memory leaks and double-fires.

EventSignatureWhen it fires
OnAdsCompletedAction<AdsCompletedArgs>All ad outcomes. Universal catch-all. Use for analytics.
OnSDKReadyActionOnce, when SDK init succeeds. Show ad-related UI here.
OnRewardGrantedAction<string>Reward earned. Arg: placement name string.
OnRewardSkippedAction<string>Rewarded ad closed without earning. Arg: placement name.
OnInterstitialClosedActionAny interstitial dismissed by the player.
 
void OnEnable()
{
    AdManager.Instance.OnSDKReady           += HandleSDKReady;
    AdManager.Instance.OnAdsCompleted       += HandleAdsCompleted;
    AdManager.Instance.OnRewardGranted      += HandleRewardGranted;
    AdManager.Instance.OnRewardSkipped      += HandleRewardSkipped;
    AdManager.Instance.OnInterstitialClosed += HandleInterstitialClosed;
}

void HandleSDKReady()                                        { ShowAdButtons(); }
void HandleAdsCompleted(AdManager.AdsCompletedArgs args)     { LogToAnalytics(args); }
void HandleRewardGranted(string placement)                  { GiveReward(placement); }
void HandleRewardSkipped(string placement)                  { ShowSkipFeedback(); }
void HandleInterstitialClosed()                              { ResumeGame(); }

void OnDestroy()
{
    if (AdManager.Instance == null) return;

Section 8

Ad-Free IAP Guard — 3-Level Trust System

🔴
Security: Reading only PlayerPrefs.GetInt("ad_free_purchased") lets any rooted Android user edit the value and get ad-free for free. The 3-level system below blocks this.
🛡️ Level 1 — In-Memory Flag

_adFreeServerVerified — private bool. Unreachable from disk. Set by SetAdFreeVerified(true).

💾 Level 2 — Server-Verified PlayerPrefs

"ad_free_server_verified" = 1. Set by SetAdFreeVerified(true). Survives app restarts. Not enough alone — Level 1 must also be set.

⏱️ Level 3 — 72h Grace Period

Covers real buyers who purchased offline. UTC timestamp stored at SetAdFree(). After 72h without server verification, ads resume.

🔒 Why Hackers Fail

Faking "ad_free_purchased" = 1 in PlayerPrefs gets no real purchase timestamp. Grace period also fails immediately. All 3 levels must pass.
