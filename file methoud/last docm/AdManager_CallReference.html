Section 1

Rewarded Ads

bool IsRewardedReady()
safe anytime
Rewarded returns bool

Returns true only when SDK is initialized AND an ad is loaded from network. Use this to show or hide your "Watch Ad" button.

watchButton.gameObject.SetActive(AdManager.Instance.IsRewardedReady());
bool ShowRewarded(string placementName, Action onRewarded = null)
requires ready
Rewarded returns bool — true if shown fires OnRewardGranted · OnRewardSkipped · OnAdsCompleted

Shows the rewarded ad immediately — no prompt UI. Returns false if not ready. The onRewarded callback fires when the SDK confirms the reward was earned, NOT on ad close. Use this when you have your own custom offer UI already shown.

void OnWatchClicked()
{
    bool shown = AdManager.Instance.ShowRewarded(
        AdManager.Placement.UnlockContent,
        onRewarded: () => { UnlockSkin(); }
    );
    if (!shown) ShowBuyDialog();
}
void ShowRewardedPrompt(string placementName, Action onAccepted, Action onDeclined = null)
v5 fix
Rewarded CORRECTED — RewardPromptConfig does not exist in AdManager v4 fires OnAdsCompleted · OnRewardGranted · OnRewardSkipped

If a rewarded ad is ready, shows it with the given placement name and fires onAccepted when reward is earned. If no ad is ready, fires onDeclined immediately. There is no RewardPromptConfig class in AdManager v4 — this method takes a plain string placement name.

// ✅ Correct v4 signature — no config object:
AdManager.Instance.ShowRewardedPrompt(
    AdManager.Placement.ExtraLives,
    onAccepted: () => { _lives += 3; UpdateHUD(); },
    onDeclined: () => { ShowGameOverScreen(); }
);

// For built-in game hooks with countdown UI, use the wrappers:
AdManager.Instance.OnGameOver(onRevived, onDied);
AdManager.Instance.OnDoubleRewardOffer(label, onDoubled, onSkipped);
void LoadRewarded()
Rewarded

Manual load trigger. Normally called automatically by the SDK lifecycle. Only call this if you believe auto-reload is stuck. Skipped silently if SDK is not initialized.

AdManager.Instance.LoadRewarded();
Section 2

Game Hook Methods

These are the methods you call from your game code. They handle the entire ad flow internally — checking readiness, showing the prompt UI, and calling your callbacks.

1
OnGameOver(Action onRevived, Action onDied = null)
continue_game · Rewarded · 5s countdown
highest value

The most important placement. Shows a revive prompt with a 5-second countdown. If no rewarded ad is ready, onDied fires immediately — fail gracefully.

AdManager.Instance.OnGameOver(
    onRevived: () => { _player.Revive(0.5f); ResumeGame(); },
    onDied:    () => { ShowDeathScreen(); }
);
2
OnDoubleRewardOffer(string label, Action onDoubled, Action onSkipped = null)
double_coins · Rewarded · 8s countdown

Shows a reward-doubling prompt. label is displayed inside the prompt UI — make it match your currency ("2× Coins", "96 Souls", "+50 Gems"). Both callbacks should give the player something so the offer always resolves cleanly.

AdManager.Instance.OnDoubleRewardOffer(
    label:     $"{earned * 2} Souls",
    onDoubled: () => { GiveSouls(earned * 2); },
    onSkipped: () => { GiveSouls(earned); }
);
3
OnDailyBonusOffer(Action onClaimed)
daily_bonus · Rewarded · no countdown

Shows a daily reward prompt with no countdown. If no ad is ready, onClaimed fires for free — graceful fallback so the player always gets their daily reward. If the player ignores the popup, onClaimed is NOT called — guard this with your own daily cooldown logic.

AdManager.Instance.OnDailyBonusOffer(
    onClaimed: () =>
    {
        GiveGems(50);
        PlayerPrefs.SetString("last_daily", DateTime.UtcNow.ToString("O"));
        PlayerPrefs.Save();
    }
);
4
OnSkipTimerOffer(string label, Action onSkipped)
skip_wait · Rewarded · 5s countdown

Shows a skip-timer prompt. label describes what is being skipped. If no ad is ready, onSkipped fires for free — player gets the skip regardless. Perfect for energy refills, cooldown timers, and crafting waits.

AdManager.Instance.OnSkipTimerOffer(
    label:     "Skip 2h energy refill",
    onSkipped: () => { _energyTimer = 0f; RefillEnergy(); }
);
5
OnLevelComplete(int levelNumber)
level_complete · Interstitial · all guards applied
1 param only
⚠
The v3 doc had this wrong as 2 params. Correct signature is void OnLevelComplete(int levelNumber) — no callback. Subscribe to OnInterstitialClosed to run code after the ad closes.
AdManager.Instance.OnLevelComplete(currentLevel);

// To run code after the interstitial closes:
void OnEnable()  => AdManager.Instance.OnInterstitialClosed += OnAdClosed;
void OnDestroy() => AdManager.Instance.OnInterstitialClosed -= OnAdClosed;
void OnAdClosed() => LoadNextLevel();
6
OnMenuOpen() · OnGameplayStart() · OnOnboardingComplete()
Lifecycle hooks · call once per event
// Returning to main menu — loads/shows banner + tries interstitial
AdManager.Instance.OnMenuOpen();

// Round/match begins — hides banner (stays loaded in memory)
AdManager.Instance.OnGameplayStart();

// Called ONCE when tutorial ends — unlocks interstitials from this point
AdManager.Instance.OnOnboardingComplete();
Section 3

Interstitial Ads

bool TryShowInterstitial(string placementName)
1 param only
Interstitial returns bool — true if shown v3 doc had 2 params — wrong fires OnInterstitialClosed · OnAdsCompleted

Runs ALL guards in order before showing: SDK ready → ad loaded → day-1 guard → tutorial guard → session cap → cooldown timer. Returns false silently if any guard fails. To react after close, subscribe to OnInterstitialClosed.

// Safe to call on any trigger — guards handle all blocking
AdManager.Instance.TryShowInterstitial(AdManager.Placement.MenuTransition);

// Add your own guard around it if needed
if (!_isBossFight)
    AdManager.Instance.TryShowInterstitial(AdManager.Placement.LevelComplete);
bool IsInterstitialReady()
safe anytime
Interstitial returns bool

Returns true if SDK initialized and an interstitial is loaded. Does NOT check guards — TryShowInterstitial checks those at show time.

if (AdManager.Instance.IsInterstitialReady())
    AdManager.Instance.TryShowInterstitial("bonus_trigger");

Section 4

Banner Ads

void LoadBanner()  ·  void ShowBanner()  ·  void HideBanner()  ·  void DestroyBanner()
Banner fires OnAdsCompleted (BannerLoaded)

LoadBanner() — creates new LevelPlayBannerAd(bannerAdUnitId), registers events, calls .LoadAd(). On load success it auto-calls ShowBanner(). Called by OnMenuOpen().

ShowBanner() — calls .ShowAd(). No-op if not loaded or already visible.

HideBanner() — calls .HideAd(). Banner stays in memory. Called by OnGameplayStart().

DestroyBanner() — unsubscribes all events, calls .DestroyAd(), nulls reference. Called by SetAdFree(). You must call LoadBanner() again to restore.

// Standard game flow — usually all you need:
AdManager.Instance.OnMenuOpen();       // banner appears on menu
AdManager.Instance.OnGameplayStart();  // banner hidden during play

// Manual control:
AdManager.Instance.ShowBanner();
AdManager.Instance.HideBanner();
AdManager.Instance.DestroyBanner();   // after IAP
bool visible = AdManager.Instance.IsBannerVisible();
Section 5

Events — Subscribe & Unsubscribe

⚠
Always unsubscribe in OnDestroy(). A missing unsubscribe causes the handler to fire in a destroyed object — NullReferenceException or double-fire next scene.
EventSignatureWhen it fires
OnAdsCompletedAction<AdsCompletedArgs>Every ad outcome — universal catch-all
OnSDKReadyActionOnce, SDK init success. Show ad UI here.
OnRewardGrantedAction<string>Reward earned. Arg = placement name.
OnRewardSkippedAction<string>Ad closed without reward. Arg = placement.
OnInterstitialClosedActionAny interstitial dismissed by player.
 
void OnEnable()
{
    AdManager.Instance.OnAdsCompleted       += HandleAdsCompleted;
    AdManager.Instance.OnSDKReady           += HandleSDKReady;
    AdManager.Instance.OnRewardGranted      += HandleRewardGranted;
    AdManager.Instance.OnRewardSkipped      += HandleRewardSkipped;
    AdManager.Instance.OnInterstitialClosed += HandleInterstitialClosed;
}

void HandleSDKReady()
    => ShowAdButtons();

void HandleAdsCompleted(AdManager.AdsCompletedArgs args)
{
    switch (args.Type)
    {
        case AdManager.AdsCompletedType.RewardedEarned:
            GiveRewardForPlacement(args.PlacementName);
            break;
        case AdManager.AdsCompletedType.RewardedSkipped:
            ShowSkipFeedback();
            break;
        case AdManager.AdsCompletedType.InterstitialClosed:
            ResumeGame();
            break;
        case AdManager.AdsCompletedType.BannerLoaded:
            AdjustLayoutForBanner();
            break;
    }
}

void HandleRewardGranted(string placement)
    => Debug.Log($"Reward earned at {placement}");

void HandleRewardSkipped(string placement)
    => Debug.Log($"Skipped at {placement}");

void HandleInterstitialClosed()
    => LoadNextScene();

void OnDestroy()
{
    if (AdManager.Instance == null) return;
    AdManager.Instance.OnAdsCompleted       -= HandleAdsCompleted;
    AdManager.Instance.OnSDKReady           -= HandleSDKReady;
    AdManager.Instance.OnRewardGranted      -= HandleRewardGranted;
    AdManager.Instance.OnRewardSkipped      -= HandleRewardSkipped;
    AdManager.Instance.OnInterstitialClosed -= HandleInterstitialClosed;
}

Consent & Privacy

⚠
IronSource.Agent.setConsent() is fully removed in v9.3.0. Use only the static methods below — they save to PlayerPrefs which the SDK reads at init time.
static void SetUserConsent(bool)  ·  static bool GetUserConsent()
Privacy · GDPR static — call on class not Instance

Saves to PlayerPrefs key "ad_user_consent". Call before first SDK init on fresh install and when player changes consent in settings.

AdManager.SetUserConsent(true);   // player agreed
AdManager.SetUserConsent(false);  // player declined
bool c = AdManager.GetUserConsent();
static void SetDoNotSell(bool)  ·  static bool GetDoNotSell()
Privacy · CCPA static — call on class not Instance

CCPA California opt-out. Saves to PlayerPrefs key "ad_do_not_sell". Expose a toggle in your privacy settings screen.

AdManager.SetDoNotSell(true);    // player opts out of data sale
bool d = AdManager.GetDoNotSell();
Section 7

Ad-Free IAP Guard

void SetAdFree()  ·  void SetAdFreeVerified(bool)  ·  bool IsAdFree()
Ad-Free IAP

SetAdFree() — call immediately after IAP purchase completes. Writes local flag + UTC timestamp (starts 72h grace), destroys banner instantly.

SetAdFreeVerified(true) — call after server validates receipt. Grants permanent server-level trust. SetAdFreeVerified(false) — invalid receipt, revokes all flags, ads resume.

IsAdFree() — single source of truth. Checks in-memory flag → server PlayerPrefs → 72h grace. Use to hide "Remove Ads" buttons.

// Step 1: immediately after Unity IAP completes
void OnPurchaseComplete(PurchaseEventArgs args)
{
    AdManager.Instance.SetAdFree();
    StartReceiptValidation(args.purchasedProduct.receipt);
}

// Step 2: after server validates
YourServer.ValidateReceipt(receipt, result =>
{
    AdManager.Instance.SetAdFreeVerified(result.isValid);
});

// Check anywhere:
if (AdManager.Instance.IsAdFree())
{
    removeAdsButton.SetActive(false);
    ShowPremiumBadge();
}
